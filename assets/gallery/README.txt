GALLERY PHOTOS GO IN THIS FOLDER
================================

Drop .jpg / .jpeg / .png files here and they appear on the Gallery page.

- Upload full-size scans. The site makes web-sized copies automatically and
  never publishes the originals, and camera/GPS metadata is stripped.
- Photos are shown in filename order. Number them to control the order:
    01-junia-salt.jpg, 02-elijah-john.jpg, 03-...
- The caption comes from the filename: "02-elijah-john.jpg" shows as
  "Elijah John". Leave the number and dashes; they're cleaned up.
- Clicking a photo opens it larger.

If this folder has no photos, the Gallery page says "Coming soon!".
